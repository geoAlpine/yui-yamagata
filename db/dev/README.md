# 開発用のシードデータ

**本番には絶対に流さない。** ここにあるのは架空の店舗・道路（名前に「（仮）」が付く）で、
災害情報として読まれると実害が出る。

`db/0*.sql` というglobで本番のマイグレーションを流す運用にしているため、
うっかり拾われないよう `db/` 直下から外してある。実際に一度、公開サイトへ
混入させる事故を起こした（2026-08-05）。

開発時のみ、明示的に指定して使う:

```bash
psql -d bousai -f db/dev/002_seed_dev.sql
psql -d bousai -f db/dev/003_seed_observations_dev.sql
```
